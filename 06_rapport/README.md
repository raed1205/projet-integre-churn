The report follows the recommended structure: cover and executive summary, introduction, data understanding,
architecture, warehouse and ETL, Power BI and DAX, predictive models (KPI, time series, LSTM / RNN, churn, leakage
check), web application and UML, limitations and perspectives, conclusion, appendices.

Rebuild it with:

```bash
python tools/build_report.py
```

(Markdown → HTML with pandoc → PDF with headless Chromium.) Every number in the report comes from the notebooks'
outputs and the warehouse checks; no figure shows a customer row.
